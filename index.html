The Architecture

Single server. Cloudflare Tunnel (no open ports). Nginx reverse proxy routing all 7 apps. Docker Compose orchestration.

Internet → Cloudflare Tunnel → Nginx Reverse Proxy (:80/:443) │ ├── /admin → React 18 + Vite Admin Dashboard :3000 ├── /resume → FastAPI + Ollama Llama 3.2 :8001 ├── /store → SvelteKit + Stripe + MinIO :8002 ├── /automate → n8n Workflow Engine :5678 ├── /homeschool → FastAPI + Ghost CMS :8003 ├── /secaudit → FastAPI + Ollama + WeasyPrint PDF :8004 ├── /alerts → Node.js + Telegram Bot + CoinGecko :8005 └── /dashboards → Apache Superset :8088 Shared Infrastructure: PostgreSQL 16 (8 databases, one per service) Redis 7 (session, cache, queue) MinIO (S3-compatible object storage) Ollama (local LLM: Llama 3.2, GPU-accelerated) Prometheus + Grafana + Loki (monitoring & alerting)
